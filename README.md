Aloura

Aloura is a lifestyle and productivity app designed specifically for women. It helps track daily tasks, wellness, mood, and personal growth in an intuitive, beautiful, and interactive interface.

Features

1. FocusZone

Task Management: Add, edit, delete, and mark tasks as complete.

Pomodoro Timer: Built-in timer to boost productivity.

Task Tags & Filters: Organize tasks using tags and filters.

Attachments & Notes: Attach files or add notes to tasks.

Productivity Heatmap: Visual representation of your productivity trends.

Energy Tracker: Track energy levels alongside tasks for optimal performance.

2. Journal

Mood Tracking: Record daily moods.

Notes & Reflections: Maintain a personal journal.

Wellness Tips: Get tips for mental and physical health.

3. Learn & Growth Goals

Personal Growth Tracker: Set and track growth goals.

Progress Insights: Visualize progress over time.

4. Period & Health Tracker

Period Logging: Record menstrual cycle details.

Health Insights: Track symptoms, cycles, and wellness patterns.

Tech Stack

Frontend: React.js

State Management: React Context API (Global state)

Styling: Tailwind CSS

Animations: Framer Motion

UI Library: Optional integration with shadcn/ui components

Data Storage: Local Storage
